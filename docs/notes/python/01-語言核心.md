# 01 語言核心

寫 Python 時最常碰到、跟 JS 差最多的部分。

## 縮排就是語法

JS 用 `{}` 標示區塊，Python 用縮排。同一層的程式碼縮排必須完全相同，
不一致就是 SyntaxError，不是風格問題。

```python
def check(x):
    if x > 0:
        return "正數"
    return "非正數"
```

慣例一律 4 個空格。層級怎麼算：函式內容比 `def` 多一層，`if` 內容再多一層。

**兩個高頻錯誤：**

`return` 縮排錯一層，會跑進 `if` 裡面變成只在某條路徑執行，或退到函式外
直接報 `'return' outside function`。前者不會報錯，只是行為錯，特別難抓。

decorator 和它裝飾的函式之間不能有空行：

```python
@app.get("/health")     # 中間空一行就 SyntaxError
def health():
    ...
```

**對策是裝 formatter，不要靠眼睛。** Python 這邊用 Ruff，見 `03-工具鏈.md`。

## 變數與型別

宣告不需要關鍵字，沒有 `let` / `const`：

```python
name = "winnie"
count = 0
```

**沒有真正的常數。** 全大寫（`MAX_SIZE = 100`）只是慣例，表示「別改我」，
語言不會阻止。相當於 JS 只有 `let` 沒有 `const`。

型別是動態的，但可以寫型別標註（見 `02-結構組織.md`）。

## truthy / falsy

falsy 的東西：`False`、`None`、`0`、`0.0`、`""`、`[]`、`{}`、`()`、`set()`

跟 JS 的重要差異：**空 list 和空 dict 是 falsy**。JS 裡 `[]` 和 `{}` 都是 truthy，
常要寫 `arr.length > 0`，Python 直接 `if arr:` 就好。

```python
if items:           # 有東西才進來，空 list 不進來
    ...
if not text:        # 涵蓋 None 和空字串兩種「沒填」
    ...
```

Python 沒有 `undefined`，只有 `None`。所以不會有 JS 那種
「`null` 和 `undefined` 要分別檢查」的麻煩。

## is 與 ==

| 運算子 | 比什麼 | JS 對應 |
|---|---|---|
| `==` | 內容相等 | 深層比較（JS 沒有內建） |
| `is` | 是不是同一個物件 | `===`（對物件而言） |

```python
[1, 2] == [1, 2]    # True，內容一樣
[1, 2] is [1, 2]    # False，兩個不同物件
```

**跟 JS 最大的差異：`==` 會比較內容。** JS 裡 `{a:1} === {a:1}` 是 False，
要用 lodash 或 `JSON.stringify`；Python 的 dict、list 直接 `==` 就是比內容。
寫測試時很好用：`assert response.json() == {"status": "ok"}`。

**`None` 一律用 `is`：**

```python
if value is None:       # 慣例寫法
if value == None:       # 能動，但不要這樣寫
```

## 可變與不可變

這是 Python 一個容易踩的坑，JS 也有但表現形式不同。

**不可變**：`int`、`float`、`str`、`tuple`、`bool`
**可變**：`list`、`dict`、`set`

不可變的東西改不了，只能產生新的：

```python
s = "hello"
s.upper()        # 回傳新字串，s 本身沒變
s = s.upper()    # 要重新指派才會變
```

**最大的坑：可變的預設參數。**

```python
def add(item, bucket=[]):     # 危險
    bucket.append(item)
    return bucket

add("a")    # ['a']
add("b")    # ['a', 'b'] ← 上次的還在！
```

預設值只在函式定義時建立一次，之後每次呼叫共用同一個 list。
正確寫法是用 `None` 當預設：

```python
def add(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

## 字串

f-string 對應 JS 的樣板字串：

```python
f"{name} 練了 {duration} 分鐘"     # `${name} 練了 ${duration} 分鐘`
```

前綴 `f` 不能省。裡面可以放任何運算式：`f"{duration // 60} 小時"`。

多行字串用三個引號，常用來寫長文字或 SQL：

```python
text = """第一行
第二行"""
```

## 迴圈

**沒有 C 式的 `for (let i = 0; ...)`。** Python 的 `for` 一律是走訪：

```python
for item in items:              # JS 的 for...of
    print(item)

for i in range(5):              # 0 到 4
    print(i)

for i, item in enumerate(items):  # 要 index 時
    print(i, item)
```

`enumerate` 對應 JS 的 `items.forEach((item, i) => ...)`，但順序相反
（Python 先 index 後 item）。

**`in` 也是成員檢查**，對應 `arr.includes(x)`：

```python
if "hiit" in training_types:
    ...
```

## 資料結構：四種與什麼時候用

| 型別 | 寫法 | JS 對應 | 什麼時候用 |
|---|---|---|---|
| list | `[1, 2, 3]` | Array | 有順序、會增刪、可重複 |
| dict | `{"a": 1}` | Object / Map | 用 key 查值 |
| set | `{1, 2, 3}` | Set | 只關心「在不在裡面」、要去重 |
| tuple | `(1, 2)` | 凍結的 Array | 固定幾個一組、不該被改 |

### list

```python
items = []
items.append(x)         # push
items.pop()             # pop
len(items)              # .length
items[-1]               # 最後一個（JS 要寫 items[items.length - 1]）
items[1:3]              # 切片，對應 slice(1, 3)
```

**list comprehension** 是 Python 版的 `map` / `filter`，很常用：

```python
[x * 2 for x in items]                  # items.map(x => x * 2)
[x for x in items if x > 0]             # items.filter(x => x > 0)
```

可讀性原則：一層很好懂就用，要巢狀兩層以上就改寫成普通迴圈。

### dict

```python
d = {"name": "winnie"}
d["name"]               # 取值，key 不存在會 KeyError
d.get("age")            # 取不到回 None，不會報錯
d.get("age", 0)         # 取不到回 0
"name" in d             # key 在不在
d["age"] = 30           # 新增或修改
```

**取值只能用 `[]`，不能用 `.`。** Python 的 dict 沒有 `d.name` 這種語法，
這是跟 JS 物件最大的差異。想用 `.` 存取就該用 class 或 Pydantic model。

### set

```python
s = {1, 2, 3}
3 in s              # O(1)，比 list 的 in 快
s.add(4)
list(set(items))    # 去重的慣用寫法
```

**主要用途是成員檢查。** 「這個值在不在這組裡面」用 set 寫最直觀也最快。

### tuple

```python
point = (10, 20)
x, y = point        # 解構，對應 JS 的 const [x, y] = point
```

**不可變**，所以能當 dict 的 key（list 不行）。函式回傳多個值時也常用：

```python
def get_range():
    return 10, 20       # 其實回傳的是 tuple

low, high = get_range()
```

## 函式

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"
```

**沒有 `function` 關鍵字，用 `def`。** 預設參數的寫法跟 JS 一樣，
但注意前面說的「可變預設值」的坑。

### 關鍵字參數

Python 可以在呼叫時指名參數，這在 JS 要靠傳物件才做得到：

```python
def create(date, type, duration, note=None):
    ...

create("2026-03-10", "running", 40)                    # 位置參數
create(date="2026-03-10", type="running", duration=40)  # 關鍵字參數
create("2026-03-10", type="running", duration=40)       # 混用，位置的要在前面
```

**參數超過三個就建議用關鍵字呼叫**，讀的人不用回頭數順序。

### *args 與 **kwargs

```python
def f(*args, **kwargs):
    ...                 # args 是 tuple，kwargs 是 dict
```

寫函式時少用（會讓簽名看不出要傳什麼），但**呼叫時展開很常用**：

```python
data = {"date": "2026-03-10", "type": "running"}
Training(**data)        # 等同 Training(date="2026-03-10", type="running")
```

對應 JS 的 `...` 展開。`*` 展開 list，`**` 展開 dict。

### 沒有寫 return 會回傳 None

```python
def f():
    pass

f()     # None，不是 undefined
```

## 作用域

**函式內指派變數，預設是建立新的區域變數**，即使外面有同名的：

```python
count = 0

def increase():
    count = count + 1       # UnboundLocalError！
```

要改外層變數得明寫 `global`（module 層級）或 `nonlocal`（外層函式）。
但**需要用到 global 通常代表設計該調整**——改成回傳值或包成 class 比較好。

`if` 和 `for` 不會建立新作用域，這跟 JS 的 `let` 不同：

```python
for i in range(3):
    pass
print(i)        # 2，迴圈變數在迴圈外還活著
```
