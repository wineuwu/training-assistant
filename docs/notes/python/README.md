## 最容易踩的幾個坑

集中放這裡，細節在各篇。

- **縮排錯一層不一定報錯**，可能只是行為錯（`return` 跑進 `if` 裡）。
  裝 Ruff extension 讓存檔自動格式化。
- **decorator 和函式之間不能有空行**，中間空一行就 SyntaxError。
- **可變的預設參數** `def f(x=[])` 會跨呼叫共用同一個 list，用 `None` 代替。
- **`|None` 不等於選填**，要不要必填看有沒有 `= 預設值`。
- **dict 取值只能 `d["key"]`**，沒有 `d.key`。
- **pytest 靠命名找測試**，名字不符會靜靜地完全不執行。
